This is a demo site for the Dawnlight theme for Pelican.

Dawnlight has:

  • Light and dark mode
  • A header menu with dropdowns
  • A footer
  • Code blocks with line numbers
  • Tables, footnotes, definition lists, and abbreviations
  • Accordions
  • Form controls and buttons
  • A blog with categories, archives, and pagination
  • A layout for legal pages

The source is in the docs/ folder of the repository.
