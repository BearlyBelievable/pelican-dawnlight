Date: 2026-09-10

Summary: Folders in pages become dropdowns.

A folder inside `content/pages/` becomes a dropdown in the header.

| Location | Result |
| --- | --- |
| `pages/contact.md` | A header link |
| `pages/Markdown/tables.md` | An item in the Markdown dropdown |
| `pages/Footer/terms.md` | A footer link |
