This is a demo site for the Dawnlight theme for Pelican.

Dawnlight has:

- [Light and dark mode]({filename}../articles/dark-mode.md)
- [A header menu with dropdowns]({filename}../articles/nav-groups.md)
- A footer
- [Code blocks]({filename}Markdown/code-blocks.md) with line numbers
- [Tables]({filename}Markdown/tables.md), [footnotes]({filename}Markdown/footnotes-and-toc.md), [definition lists]({filename}Markdown/lists-and-quotes.md), and [abbreviations]({filename}Markdown/headings-and-text.md#abbreviations)
- [Accordions]({filename}Markdown/accordions.md)
- [Form controls and buttons]({filename}Components/forms-and-buttons.md)
- A [blog]({category}Announcements) with categories, archives, and pagination
- A layout for [legal pages]({filename}Footer/terms.md)

The source is in the [`docs/`](https://github.com/BearlyBelievable/pelican-dawnlight/tree/main/docs)
folder of the repository.
